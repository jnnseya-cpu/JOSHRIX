# JOSHRIX Studio — Super Admin Control Centre

The Super Admin Centre is the command bridge for Groupe Nseya Digital / JNN Global platform operators. It provides omniscient, real-time visibility and intervention capability across every layer of the OS.

| Module | What Admins See | Actions Available |
|---|---|---|
| Operator Management | All operators, tiers, KYC status, ACU balance, forge history, support tickets, flags | Suspend, verify, upgrade, downgrade, credit ACU, add notes, export data |
| Forge Pipeline Monitor | All active forge cycles across all operators; agent status; ACU consumption rate; error rate | Terminate cycles, reassign queue priority, restart failed agents, view full logs |
| Revenue Command Centre | Real-time MRR, ARR, ACU revenue, marketplace GMV, BitriPay settlement status, refunds, disputes | Trigger manual settlements, process refunds, adjust commission rates |
| Compliance Dashboard | All active KYC/AML flags, IP risk escalations, age rating disputes, GDPR requests | Approve/reject flags, trigger manual reviews, escalate to legal, export compliance reports |
| Agent Governance Panel | All agent instances, instruction compliance scores, anomaly alerts, model usage costs | Override agent instructions, pause agent classes, adjust model routing |
| Security Operations Centre | Live threat feed, fraud score distribution, failed auth attempts, API abuse incidents | Block IPs, revoke API keys, suspend accounts, trigger security audits |
| System Health Dashboard | Uptime, latency percentiles, error rates, queue depths, database performance, CDN status | Trigger auto-scaling, rollback deployments, open incident tickets |
| Marketplace Operations | All listings, flagged content, DMCA requests, pricing anomalies, seller fraud signals | Remove listings, freeze seller accounts, process DMCA, adjust featured placements |
| Audit Log Viewer | Full immutable audit trail with actor, action, resource, IP, timestamp | Search, filter, export, escalate entries to compliance or legal |
| API Partner Management | All API keys, usage volumes, rate limit violations, revenue attributed | Revoke keys, adjust rate limits, send notices, manage partner tiers |
