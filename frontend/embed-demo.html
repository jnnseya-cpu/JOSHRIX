Embed SDK

Your Game. Every Website.

One script tag embeds any certified JOSHRIX game on any site — a blog, a school page, a fan community. Every embed carries the Forge chip, so every player is one tap from becoming a creator. Distribution without portals, without fees.

1 · Paste this anywhere

<script src="https://joshrix.com/assets/embed.js" data-game="penalty-king-3d" data-width="100%" data-ratio="0.6"></script>

That's the whole integration. The SDK renders a framed, branded player with the ⚡ Forge chip, and reports an anonymous share.embed_loaded event to the Forge Graph. It never touches the host page beyond its own container.
