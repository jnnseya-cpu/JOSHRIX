The Autonomous Fleet

Seven Agents. One Forge Cycle.

Input a concept. The fleet executes in orchestrated parallel clusters — synthesising, building, validating, and publishing commercial-grade game IP with no manual production bottleneck.

AGT.01

Idea Agent

Turns a prompt in any language into a full brief — genre, mechanics, narrative and art direction — with every player-facing string written in the language you used, not translated afterwards.

AGT.02

Strategic Agent

Settles the shape of the thing before a single asset is built: who it is for, how long a session runs, what the difficulty curve does, and which of the two build targets suits it.

AGT.03

Code Agent

Writes the game: loop, input, collision, scoring, win and lose states, and the wiring to the 3D runtime. Every build must parse, draw a canvas and contain a real game loop before you are shown it.

AGT.04

Asset Agent

Casts the game from the included library — 2,591 models, 281 of them rigged and animated, and 2,553 sprites — and picks the palette, lighting and audio so one build looks like one game.

AGT.05

Economy Agent

Proposes the in-game economy and a starting price at forge time — currency sinks, reward pacing, and what to charge — as a draft you edit, not a decision made for you.

AGT.06

QA Agent

Runs the gates a build has to clear: it must parse, it must play, and it is scanned for outside network calls, password fields, hidden eval and embedded pages. Anything that trips a gate is discarded and another provider is asked.

AGT.07

Deployment Agent

One shareable link the moment human moderation approves — hosted, playable on any phone or desktop, no store review and no install. Store listings are a paid service you can request per game.

The Operating Divisions

Behind the seven fleet stages sits a hierarchical multi-agent organisation, governed by the Executive Orchestrator — which maintains the shared game specification (JXSL), versioned state, dependency graph, agent permissions, cost limits, and decision logs.
