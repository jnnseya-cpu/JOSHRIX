# FBX-only character packs

Copy a pack in here ONLY when it has no glTF folder. Anything with glTF goes to
`../characters/` instead — that path is lossless and much smaller.

The ten Quaternius packs that belong here, because they predate glTF:

- Animated Men Characters - Feb 2019
- Animated Women Characters - Feb 2019
- Animated Robot - Oct 2018
- Easy Animated Enemy Pack - Jan 2019
- Fruit Characters Animated - Mar 2017
- Man Animated - Oct 2017
- Woman Animated - Dec 2017
- Zombie Animated - Jan 2018
- Posed Background Characters - Aug 2018
- Old  (check it first — it is probably superseded duplicates)
