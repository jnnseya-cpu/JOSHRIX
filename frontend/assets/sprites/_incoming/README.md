# 2D sprite packs — drop them here

Spritesheets, tiles, icons, UI kits. Copy the whole pack folder in.

The `.gitignore` here keeps the art (`.png` `.jpg` `.svg`) and the atlas
descriptors (`.xml` `.json` `.fnt`) that say how to cut a spritesheet up. A
spritesheet without its descriptor is one large image nobody can slice, so both
halves matter.

Excluded from the Vercel deploy, so nothing here slows the site down.

See `/UPLOADING-ASSETS.md` in the repository root for the full instructions.
